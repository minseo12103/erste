# Octopusdream — Windows 프로토타입

`WOC_Ct_Building_Park` 맵에서 구체 문어와 원통 잠수부로 플레이하는 숨바꼭질 프로토타입이다.

## 실행

1. **이 폴더 전체를 함께 보관하거나 전달한다.** 실행 파일만 복사하면 게임 데이터와 DLL이 빠진다.
2. `Octopusdream.exe`를 실행한다.
3. 혼자 확인하려면 **혼자 연습 → 연습 시작**을 선택한다. 잠수부로 연습하려면 시작 전에 중앙 작살 근처에서 `E`로 지원한다.

## Steam 멀티플레이

- 참가자마다 **다른 Steam 계정**, 같은 게임 빌드가 필요하다. 처음에는 PC 두 대에서 확인한다.
- 두 PC 모두 Steam에 로그인하고 **이 프로토타입을 먼저 실행**한다.
- 호스트는 **Steam 방 만들기**, 참가자는 **Steam 방 찾기** 또는 숫자 **방 ID 참가**를 사용한다. 호스트의 **친구 초대**도 사용할 수 있다.
- 개발용 App ID는 `480`이다. 실행 파일 옆 `steam_appid.txt`를 유지한다. Steam에는 **Spacewar**로 표시될 수 있다.
- 라운드 시작 후에는 새로 참가할 수 없다. 호스트가 종료하면 방도 종료된다. 최대 인원은 호스트 포함 20명이다.
- Steam 계정이 준비되지 않았다면 **LAN / 로컬 연결 테스트**를 이용할 수 있다. 같은 PC에서 두 창을 띄울 때 참가 주소는 `127.0.0.1`, 기본 포트는 TCP `27020`이다. `-noSteam` 실행 인수는 Steam 초기화를 건너뛴다.

## 조작

| 키 | 동작 |
|---|---|
| `WASD`, `Space`, `Ctrl` | 이동, 상승, 하강 |
| `F` | 문어 색칠 편집 시작 / 완료 |
| 편집 중 좌클릭 드래그 / 우클릭 드래그 | 색칠 / 카메라 회전 |
| 편집 중 휠 / SOFTNESS 슬라이더 | 브러시 크기 / 부드러움 0~10 |
| `V` | 발밑 표면 색을 문어 전체에 즉시 적용 |
| 대기실 중앙 작살 근처 `E` | 잠수부 지원 / 취소 |
| 수색 중 `E` | 문어: 충전된 먹물 / 잠수부: 적외선 탐지 |
| 잠수부 좌클릭 | 작살 발사 |
| `Esc` / `F1` / 포획 후 `Q` | 마우스 해제·조작 복귀 / 도움말 / 관전 대상 변경 |

색은 색상·채도 평면과 세로 밝기 막대에서 선택하거나 RGB 0~255 값을 직접 입력한다. 숫자 입력은 Enter로 마친다. 바닥 근처에서 SOFTNESS 5는 둥글게 눌리고 가장자리가 처지며, 10은 얇게 퍼져 단차를 따라 늘어진다. Space로 표면에서 떨어지면 공중 형태로 돌아간다.

기본 라운드는 **숨기 30초 → 수색 180초**다. 모든 문어가 잡히면 잠수부 팀, 산소가 소진될 때 문어가 남아 있으면 문어 팀이 승리한다. 먹물은 술래 시야 안에서 정면 조준·적외선 탐지를 피하며 충전하고, 라운드당 한 번 사용할 수 있다. `Esc`를 눌러도 라운드 시간은 계속 흐른다.

Steamworks.NET 라이선스와 사용 버전·출처는 `ThirdParty` 폴더에 포함되어 있다. App ID 480은 개발 테스트용이며, 최종 Steam 출시에서는 게임의 고유 App ID를 사용한다.
