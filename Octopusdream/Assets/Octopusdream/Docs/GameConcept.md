# Octopusdream — 현재 프로토타입 기획

## 게임의 목적

Steam PC 출시를 목표로 하는 최대 20인 호스트 멀티플레이 숨바꼭질 게임이다. 문어 팀은 몸을 색칠하거나 주변 표면의 색을 즉시 복사해 숨고, 잠수부 팀은 정해진 시간 안에 문어를 찾아 잡는다. 수색 제한시간은 잠수부의 산소 잔량으로 표현한다.

**문어가 제한시간까지 살아남는 것이 승리 목표다.** 다리 수집이나 탈출 지점 이동 목표는 없다. 캐릭터를 직접 조각하는 기능도 현재 기획에 포함하지 않는다.

## 맵과 캐릭터

- 테스트 맵: `Assets/WOC/Scenes/WOC_Ct_Building_Park.unity`.
- 문어: 구체 임시 모델, 3인칭.
- 잠수부: 원통 임시 모델, 1인칭.
- 최종 문어·잠수부 모델은 사용자가 별도로 제공한다. 임시 외형은 플레이어의 `Replaceable character visual` 자식으로 분리되어 있어 이동·네트워크 루트와 구분된다.
- SOFTNESS는 바닥과 단차에 닿는 외형을 변형한다. 이동용 충돌체는 고정 크기를 유지하고, 작살과 색칠은 변형된 문어 표면을 기준으로 판정한다.

## 한 라운드의 흐름

1. **대기실:** 모두 문어로 참가한다. 중앙 작살 3.5m 안에서 `E`를 누르면 잠수부에 지원하고, 원통·1인칭 모습으로 전환해 미리 확인한다. 다시 `E`를 누르면 지원을 취소한다.
2. **역할 선정:** 호스트가 술래 인원을 정한다. 지원자가 많으면 지원자 중 무작위로 고르고, 부족하면 나머지 참가자 중 무작위로 충원한다. 실제 역할은 라운드 시작 시 확정한다. 문어가 최소 한 명 남도록 술래 수를 제한한다.
3. **숨기 30초:** 문어는 맵을 이동하며 숨거나 색칠한다. 잠수부는 잠수 장비 준비 화면에서 대기하며 이동과 수색을 할 수 없다.
4. **수색 180초:** 잠수부의 산소가 감소한다. 잠수부는 작살과 적외선을, 문어는 색칠·주변색 복사·먹물을 사용한다.
5. **포획과 승패:** 작살이 한 번 명중하면 문어가 포획되어 관전한다. 모든 문어를 잡으면 잠수부 팀 승리, 시간이 끝날 때 살아 있는 문어가 있으면 문어 팀 승리다.
6. **다음 라운드:** 호스트가 결과 화면에서 대기실로 돌아갈 수 있다. 대기실에 돌아오면 역할 지원과 스킬 상태가 초기화된다.

## 색칠과 주변색 복사

`F`를 누르면 문어가 멈추고 편집모드가 열린다. 화면의 문어에 좌클릭 드래그로 칠하고, 우클릭 드래그로 카메라를 회전해 다른 면을 칠한다. 색상창에는 가로 색상·세로 채도 평면, 흰색부터 검정까지 이어지는 별도 밝기 막대, RGB 0~255 숫자 입력과 `−`/`+`, 선택 색 미리보기가 있다. 브러시 크기는 슬라이더 또는 마우스 휠로 변경한다. 숫자를 입력하는 동안 게임 단축키는 정지하며 Enter로 입력을 마친다. 다시 `F`를 누르거나 편집 완료를 누르면 이동 모드로 돌아간다.

`V`는 문어 바로 아래 표면을 읽어 **문어 전체에 색을 즉시 적용**한다. 표면 텍스처의 해당 위치 색과 재질 색을 함께 반영한다. 조명과 그림자까지 포함한 화면 픽셀을 복사하는 방식은 아니다. 기존 페인팅은 전체 색으로 덮어쓴다.

색칠은 네트워크로 다른 참가자에게 전달되며, 대기실에 새로 참가한 사람도 현재 색칠 상태를 받는다. 방에 있는 동안에는 캐릭터의 색칠을 유지한다. 현재 프로토타입에는 앱 종료 후 그림을 저장하거나 불러오는 기능이 없다.

## SOFTNESS 0~10

참고 영상에서 설명한 물체의 부드러움 차이를 캐릭터에 적용하는 설정이다. 편집창의 슬라이더로 변경한다.

- **0:** 바닥에 닿는 단단한 구체 형태를 유지한다.
- **5:** 둥근 부피감을 유지하면서 바닥 접촉면이 눌리고, 단차 밖으로 나온 가장자리가 처진다.
- **10:** 몸체가 낮고 넓게 퍼지고 단차를 따라 얇게 늘어진다.
- 표면에 가까이 내려오면 접촉 변형이 적용된다. `Space`로 헤엄쳐 올라가 표면에서 떨어지면 공중 형태로 복원된다. 이동과 충돌에도 탄성 반응이 생긴다.
- 브러시 크기나 색칠 방식과 독립적인 값이다.
- 표면 접촉을 이용한 메시 변형을 사용한다. 이동 충돌 크기는 일정하며, 작살은 현재 변형된 몸체와의 교차로 명중을 판정한다.

## 잠수부의 작살과 적외선

| 항목 | 현재 기본값 |
|---|---|
| 작살 | 좌클릭, 사거리 25m, 발사 간격 1.1초 |
| 포획 | 문어에게 1회 명중하면 포획 |
| 적외선 발동 | `E` |
| 탐지 거리 | 22m |
| 강조 지속시간 | 3.5초 |
| 재사용 대기시간 | 20초 |

적외선은 발동 순간 잠수부 앞쪽에 있고 장애물에 가려지지 않은 문어를 찾는다. 해당 문어는 잠깐 밝게 강조되며 자신의 화면에서도 탐지 경고를 확인한다. 문어가 벽 뒤로 가면 잠수부 화면에서 벽을 뚫고 보이지 않는다.

현재 시야 판정은 카메라 방향을 기준으로 한 원뿔로 근사한다. 실제 화면의 가로·세로 경계와 완전히 일치하는 판정은 후속 조정 대상이다. 먹물로 시야가 가려진 동안에는 적외선을 사용할 수 없다.

## 문어의 먹물

먹물은 **라운드당 최대 한 번** 사용할 수 있다. 시작할 때는 잠겨 있으며, 미발견 점수가 100에 도달하면 `E`로 사용할 수 있다.

프로토타입에서 미발견 점수는 다음 상태를 게임 규칙으로 판정해 쌓는다.

- 잠수부의 시야 범위 안에 있고 장애물에 가려져 있지 않다.
- 잠수부가 문어를 정면으로 조준하고 있지 않다.
- 문어가 적외선에 탐지되어 강조되는 상태가 아니다.
- 해당 잠수부는 먹물에 시야가 가려진 상태가 아니다.

사람이 실제로 문어를 알아봤는지 판단하는 기능은 아니다. 위 조건에서 기본적으로 초당 14점씩 쌓인다. 사용 순간 문어 주변 **5m 안의 잠수부**에게 **5초 동안** 시야 방해를 준다. 사용 후에는 같은 라운드에서 다시 충전되지 않는다.

## 조작표

| 키 | 기능 |
|---|---|
| `WASD` | 이동 |
| `Space` / `Ctrl` | 위 / 아래로 이동 |
| `F` | 문어 색칠 편집 시작 / 완료 |
| 편집 중 좌클릭 드래그 | 색칠 |
| 편집 중 우클릭 드래그 | 편집 카메라 회전 |
| 편집 중 휠 | 브러시 크기 |
| `V` | 몸체 아래 표면 색을 가져와 전체에 적용 |
| `E` | 대기실 술래 지원, 수색 중에는 역할별 스킬 |
| 잠수부 좌클릭 | 작살 발사 |
| `Esc` | 편집 종료 또는 마우스 해제 / 조작 복귀 |
| `F1` | 도움말 표시 전환 |
| 포획 후 `Q` | 관전 대상 변경 |

## 멀티플레이와 현재 범위

Steam App ID **480**을 사용하고, 호스트를 포함해 최대 **20명**으로 방을 구성한다. 로비에는 프로젝트 식별값과 통신 프로토콜 버전을 붙여 검색·입장 시 확인한다. 이동·포획·스킬·라운드 진행은 호스트가 판정한다.

새 참가자는 대기실에서만 입장할 수 있다. 호스트가 나가거나 연결이 끊기면 방이 종료된다. 호스트 이전이나 진행 중인 라운드에 재접속하는 기능은 현재 포함하지 않는다.

혼자 연습에는 봇 세 명이 추가된다. 문어로 시작하면 문어 봇 두 마리와 잠수부 봇 한 명이 배치된다. 잠수부 봇은 방향을 돌리며 탐지하지만 작살을 쏘지 않는다. 직접 잠수부를 선택하면 다른 참가자는 모두 문어 봇으로 배정된다. 문어의 위장과 먹물 충전, 잠수부의 작살·탐지 조작을 확인하기 위한 연습 환경이다.

이 문서는 구현된 프로토타입의 기본값을 설명한다. 최종 캐릭터·UI·밸런스·상용 출시 품질을 확정하는 문서는 아니다. 실제 Steam 계정 두 개의 연결과 실제 20인 환경 성능은 별도 확인이 필요하다. 테스트 방법은 [MultiplayerTesting.md](MultiplayerTesting.md)에 정리한다.
