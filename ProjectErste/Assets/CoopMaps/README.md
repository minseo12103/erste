# 맵 구간 제작과 협업

1. Unity에서 `Assets/CoopPrototype/MapEditor/Scenes/MapEditor.unity`를 열거나 `Tools > Shape Coop > Map Editor > Open`을 선택합니다.
2. 창에서 구간 이름을 입력하고 **새 구간 만들기**를 누릅니다. `Assets/CoopMaps/Sections/<이름>_<고유 ID>/`에 그 구간 전용 `Work.unity`와 저장될 `Section.prefab` 경로가 만들어집니다. 각자 이 버튼으로 새 구간을 만들어야 합니다.
   이미 만든 구간은 **기존 구간 열기**에서 이름 또는 경로로 검색한 뒤 **열기**를 누릅니다. 이름이 같을 때는 함께 표시된 ID와 경로로 구분합니다. 열기 전에 현재 씬에 저장하지 않은 변경이 있으면 Unity가 저장 여부를 묻습니다.
3. 팔레트에서 지형, 시작 마커 또는 목표 구역을 Scene 화면으로 끌어 놓습니다. 격자 맞춤을 켜고 끌 수 있으며, Scene의 W/E/R 도구로 이동·회전·크기를 조절합니다. 팔레트로 놓은 물체는 자동으로 `Map Section` 아래에 들어갑니다. 다른 물체를 직접 추가할 때도 이 루트 아래에 넣어야 저장됩니다.
4. 구간 테스트의 **자동: 플레이어 시작 우선**에서는 `Marker_PlayerStart`가 있으면 그 위치에서 시작하고, 없으면 기본 `Marker_TestStart`를 사용합니다. 다른 위치에서 시험하려면 **별도 테스트 시작**을 선택하고 기본 `Marker_TestStart`를 옮기거나, 마커를 선택한 뒤 **선택한 마커를 테스트 시작으로** 누르세요. **테스트 위치 클릭 지정**도 별도 테스트 시작으로 전환합니다. 창의 **실제 테스트 시작**과 좌표에서 적용될 위치를 확인할 수 있습니다. 삼각형·사각형·원 중 도형을 고르고 **선택 도형으로 테스트 실행**을 누릅니다. Steam 계정 없이 현재 플레이어 물리로 테스트할 수 있습니다. R 또는 화면 버튼으로 테스트를 재시작합니다. 기본적으로 공은 테스트 시작 지점 옆에서 생성됩니다. `Map Test Settings`에서 공 위치와 카메라를 세부 조정할 수 있습니다.
5. **현재 구간을 프리팹으로 저장**을 누르고 해당 구간 폴더 전체와 각 `.meta` 파일을 함께 커밋합니다. 작업 씬과 프리팹의 ID 및 GUID를 보존하려면 파일을 직접 복사하기보다는 Unity 에디터에서 새 구간을 만드세요.

구간 저장 전 누락된 스크립트와 끊어진 오브젝트 참조를 검사합니다. 렌더러에 2D 충돌체가 없을 때는 장식용일 수 있으므로 확인 메시지를 표시합니다. 구간에 시작점이나 목표가 없어도 저장할 수 있으며, 이들은 전체 맵을 조합할 때 확인합니다.

팔레트에서 **연속 배치**를 켜고 프리팹을 선택하면 Scene에서 반복해서 클릭하여 배치할 수 있습니다. Scene에 표시되는 반투명 미리보기로 확인하고 `[` / `]`로 15도씩 회전하며 `Esc`로 종료합니다. 드래그로 놓을 때도 미리보기가 표시되고 회전·격자 설정이 적용됩니다. **플레이어 위치 클릭 지정** 및 **공 위치 클릭 지정** 버튼으로 테스트 위치를 클릭해 지정할 수 있습니다. 별도로 지정한 테스트 공 위치는 게임의 실제 공 시작 마커에 영향을 주지 않습니다.

## 배치 오브젝트 추가

`Assets/CoopPrototype/MapEditor/에디터배치용오브젝트`에 배치할 프리팹을 넣고 맵 에디터에서 **큰 팔레트 창 열기**를 누릅니다. 팔레트의 **새로고침**과 **배치용 폴더 보기**로 목록과 폴더를 확인할 수 있습니다. 큰 썸네일을 Scene으로 끌면 현재 구간 안에 배치됩니다. 팔레트 창은 Unity의 다른 창처럼 크기를 바꾸거나 도킹할 수 있습니다.

팔레트에서 오브젝트를 클릭하면 아래에서 `배치용`, `기능 오브젝트`, `시작 지점`, `목표 지점`, `연결점` 태그를 선택할 수 있습니다. **새 태그**로 다른 이름도 추가할 수 있고, 하나의 프리팹에 여러 태그를 붙일 수 있습니다. 위쪽의 태그 필터나 검색으로 찾아보세요. 태그는 각 프리팹의 `.meta`에 저장되는 편집기 분류이며, Unity의 게임 오브젝트 Tag나 게임 동작을 변경하지 않습니다. 팀에서 공유하려면 변경된 프리팹 `.meta`를 커밋하세요. 같은 프리팹의 태그를 동시에 수정하면 해당 `.meta`에 충돌이 날 수 있습니다.

폴더 안에 하위 폴더를 만들면 첫 번째 하위 폴더 이름이 분류가 됩니다. 더 깊은 하위 폴더의 프리팹도 검색하며, 폴더 바로 아래에 추가한 프리팹은 `기타`에 표시됩니다. 기본 지형과 마커는 기존 분류에 유지됩니다. 프리팹의 스프라이트와 충돌체, 동작은 제작자가 설정해야 하며, 함께 사용하는 리소스와 `.meta` 파일도 Git에 포함하세요.

## 기능 오브젝트

팔레트의 **기능 오브젝트** 폴더 또는 태그에서 프리팹을 찾아 배치합니다. 각 프리팹의 `Map Gimmick` 컴포넌트에서 시간, 힘, 속도와 거리 등을 조절하고, 영역형 오브젝트는 `Box Collider 2D`의 크기와 위치로 적용 범위를 조절합니다. 보이는 기본 도형은 임시 표현이며 `Visuals (replaceable)`의 스프라이트를 교체할 수 있습니다. 팔레트에서 변경한 프리팹과 그 `.meta`를 함께 공유하세요.

- **무너지는 모래 상자:** 공이나 플레이어가 위에 닿으면 기본 1.5초 뒤 부서집니다. `Activation Delay`로 시간을 조절합니다.
- **공기 환풍구:** 표시된 영역 안의 공을 위로 밀어 올립니다. 바닥에 환풍구를 놓고 `Force`와 영역 크기를 조정합니다.
- **도르래 연동 발판:** 한쪽에 공이나 플레이어가 올라가면 그쪽이 내려가고 반대쪽이 올라갑니다. `Travel`, `Pulley Speed`로 이동을 조절합니다.
- **기름 웅덩이:** 바닥 위에 얇은 검은 표시를 맞춰 놓습니다. 영역에 닿은 공과 플레이어의 마찰을 없애고, 플레이어는 미끄러지며 이 영역에서 시작한 대시는 지속 시간이 3배입니다. 충돌이나 영역을 벗어나는 상황에 따라 실제 이동 거리는 달라집니다.
- **무거운 시멘트 포대:** 공이 닿는 순간 공의 선속도와 각속도를 0으로 만듭니다.
- **용접 스파크 구역:** 장치를 위쪽에 놓으면 아래로 스파크가 뻗으며 처음 닿은 물체에서 멈춥니다. 닿은 플레이어는 `Effect Seconds` 동안 행동할 수 없습니다. 이미 F로 고정된 플레이어의 고정 해제는 가능합니다. `Active Seconds`, `Inactive Seconds`, `Beam Range`를 조정할 수 있습니다.
- **움직이는 타워크레인 빔:** 중심을 기준으로 회전하는 충돌 발판입니다. `Rotation Speed`의 부호와 크기로 방향과 속도를 정합니다.
- **수압 장벽:** 천장에 놓으면 아래로 물이 흐르며 영역 안의 공을 아래로 밉니다. 삼각형 플레이어가 공 위쪽에서 물줄기를 가리면 그 아래 공은 보호받고 표시도 양옆으로 갈라집니다.
- **부실공사 벽돌 벽:** 공이 `Impact Speed` 이상의 충돌 속도로 부딪힐 때만 부서집니다.
- **산업용 대형 자석:** 천장에 놓으면 주기적으로 범위 안의 플레이어와 공을 자석 쪽으로 끌어당깁니다. 조작 방향을 바꾸거나 행동을 막지 않습니다.
- **액체 질소 가이저:** 기본적으로 3초 주기로 분출하고 닿은 플레이어를 `Effect Seconds` 동안 제자리에 고정합니다. 시간이 지나면 자동으로 풀리며, 이전에 F로 직접 고정했던 상태는 유지됩니다.

맵 테스트와 실제 게임의 재시작은 부서진 상자·벽, 움직이는 발판과 상태 이상을 초기 상태로 되돌립니다. 실제 멀티플레이에서는 호스트가 기믹과 물리를 판정하고 참가자들에게 상태를 보냅니다.

## 게임에 연결

**맵 구간 조합 화면 열기** 또는 `Tools > Shape Coop > Map Editor > Map Assembly`에서 새 조합을 만듭니다. 조합 씬은 `Assets/CoopMaps/Assemblies/<이름>_<고유 ID>/Assembly.unity`에 저장됩니다. 구간 프리팹을 선택해 추가하거나 Project 창에서 Scene으로 끌어 놓고, Scene 이동 도구로 구간을 배치합니다. 목록의 화살표로 순서를 바꾸고 항목을 눌러 선택할 수 있습니다.

구간 작업 씬에서 팔레트의 **구간 입구**와 **구간 출구**를 원하는 연결 지점에 배치해 프리팹을 저장하면, 조합 화면에서 구간을 선택하고 **선택 구간의 입구를 이전 구간 출구에 맞추기**를 눌러 연결할 수 있습니다. 한 구간에 같은 종류의 연결점이 여러 개이면 첫 번째를 사용합니다.

**조합 문제 검사**로 시작점·목표와 구간 상태를 확인한 뒤 **조합 씬 저장**, **현재 조합을 게임에 적용**을 누릅니다. 게임 적용은 공통 `Assets/CoopPrototype/Prefabs/PrototypeSystem.prefab`의 `Prototype Game > Map Sections`를 변경하므로 팀에서 통합 담당자가 처리하세요. 조합 씬에서는 구간의 XY 위치만 변경할 수 있고 구간 내부 수정은 원본 구간 작업 씬에서 해야 합니다. 변경을 마친 조합 씬과 프리팹, 각 `.meta` 파일을 함께 커밋하세요.

Inspector에서 직접 구간을 등록하는 기존 방법도 사용할 수 있습니다. 별도로 지정한 구간이 없으면 기존 테스트 맵이 그대로 사용됩니다. 연결한 구간들에는 전체적으로 `Marker_PlayerStart`와 `Marker_BallStart`를 하나씩 두고, 목표가 필요한 곳에 `Goal_Area`를 배치하세요. 같은 종류의 시작 마커가 여러 개면 배열 순서상 처음 발견된 마커를 사용합니다. 테스트 시작 마커는 실제 플레이 시작 위치에 영향을 주지 않습니다. 실제 플레이에서는 기본적으로 공을 카메라가 따라가며, `Follow Ball In Authored Maps`로 끌 수 있습니다.

Git에서는 서로 다른 고유 구간 폴더가 별도 파일이어서 각자 제작한 구간을 독립적으로 올릴 수 있습니다. 같은 구간 파일이나 공통 `PrototypeSystem.prefab`을 동시에 수정하는 경우에는 여전히 충돌할 수 있으므로, 구간 담당을 나누고 메인 맵 조합은 통합 담당자가 하세요. 모든 플레이어는 동일한 구간 설정이 포함된 같은 게임 빌드를 사용해야 합니다.
