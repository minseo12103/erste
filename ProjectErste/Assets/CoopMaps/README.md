# 맵 구간 제작과 협업

1. Unity에서 `Assets/CoopPrototype/MapEditor/Scenes/MapEditor.unity`를 열거나 `Tools > Shape Coop > Map Editor > Open`을 선택합니다.
2. 창에서 구간 이름을 입력하고 **새 구간 만들기**를 누릅니다. `Assets/CoopMaps/Sections/<이름>_<고유 ID>/`에 그 구간 전용 `Work.unity`와 저장될 `Section.prefab` 경로가 만들어집니다. 각자 이 버튼으로 새 구간을 만들어야 합니다.
3. 팔레트에서 지형, 시작 마커 또는 목표 구역을 Scene 화면으로 끌어 놓습니다. 격자 맞춤을 켜고 끌 수 있으며, Scene의 W/E/R 도구로 이동·회전·크기를 조절합니다. 팔레트로 놓은 물체는 자동으로 `Map Section` 아래에 들어갑니다. 다른 물체를 직접 추가할 때도 이 루트 아래에 넣어야 저장됩니다.
4. 기본 `Marker_TestStart`를 원하는 테스트 지점으로 옮기거나 다른 마커를 선택하고 **선택한 마커를 테스트 시작으로** 누릅니다. 삼각형·사각형·원 중 도형을 고르고 **선택 도형으로 테스트 실행**을 누릅니다. Steam 계정 없이 현재 플레이어 물리로 테스트할 수 있습니다. R 또는 화면 버튼으로 테스트를 재시작합니다. 기본적으로 공은 테스트 시작 지점 옆에서 생성됩니다. `Map Test Settings`에서 공 위치와 카메라를 세부 조정할 수 있습니다.
5. **현재 구간을 프리팹으로 저장**을 누르고 해당 구간 폴더 전체와 각 `.meta` 파일을 함께 커밋합니다. 작업 씬과 프리팹의 ID 및 GUID를 보존하려면 파일을 직접 복사하기보다는 Unity 에디터에서 새 구간을 만드세요.

구간 저장 전 누락된 스크립트와 끊어진 오브젝트 참조를 검사합니다. 렌더러에 2D 충돌체가 없을 때는 장식용일 수 있으므로 확인 메시지를 표시합니다. 구간에 시작점이나 목표가 없어도 저장할 수 있으며, 이들은 전체 맵을 조합할 때 확인합니다.

팔레트에서 **연속 배치**를 켜고 프리팹을 선택하면 Scene에서 반복해서 클릭하여 배치할 수 있습니다. Scene에 표시되는 반투명 미리보기로 확인하고 `[` / `]`로 15도씩 회전하며 `Esc`로 종료합니다. 드래그로 놓을 때도 미리보기가 표시되고 회전·격자 설정이 적용됩니다. **플레이어 위치 클릭 지정** 및 **공 위치 클릭 지정** 버튼으로 테스트 위치를 클릭해 지정할 수 있습니다. 별도로 지정한 테스트 공 위치는 게임의 실제 공 시작 마커에 영향을 주지 않습니다.

## 배치 오브젝트 추가

`Assets/CoopPrototype/MapEditor/에디터배치용오브젝트`에 배치할 프리팹을 넣고 맵 에디터의 **프리팹 목록 새로고침**을 누릅니다. **배치용 폴더 보기**를 누르면 Unity Project 창에서 해당 폴더를 찾을 수 있습니다. 팔레트에 표시된 프리팹을 Scene으로 끌면 현재 구간 안에 배치됩니다.

폴더 안에 하위 폴더를 만들면 첫 번째 하위 폴더 이름이 분류가 됩니다. 더 깊은 하위 폴더의 프리팹도 검색하며, 폴더 바로 아래에 추가한 프리팹은 `기타`에 표시됩니다. 기본 지형과 마커는 기존 분류에 유지됩니다. 프리팹의 스프라이트와 충돌체, 동작은 제작자가 설정해야 하며, 함께 사용하는 리소스와 `.meta` 파일도 Git에 포함하세요.

## 게임에 연결

**맵 구간 조합 화면 열기** 또는 `Tools > Shape Coop > Map Editor > Map Assembly`에서 새 조합을 만듭니다. 조합 씬은 `Assets/CoopMaps/Assemblies/<이름>_<고유 ID>/Assembly.unity`에 저장됩니다. 구간 프리팹을 선택해 추가하거나 Project 창에서 Scene으로 끌어 놓고, Scene 이동 도구로 구간을 배치합니다. 목록의 화살표로 순서를 바꾸고 항목을 눌러 선택할 수 있습니다.

구간 작업 씬에서 팔레트의 **구간 입구**와 **구간 출구**를 원하는 연결 지점에 배치해 프리팹을 저장하면, 조합 화면에서 구간을 선택하고 **선택 구간의 입구를 이전 구간 출구에 맞추기**를 눌러 연결할 수 있습니다. 한 구간에 같은 종류의 연결점이 여러 개이면 첫 번째를 사용합니다.

**조합 문제 검사**로 시작점·목표와 구간 상태를 확인한 뒤 **조합 씬 저장**, **현재 조합을 게임에 적용**을 누릅니다. 게임 적용은 공통 `Assets/CoopPrototype/Prefabs/PrototypeSystem.prefab`의 `Prototype Game > Map Sections`를 변경하므로 팀에서 통합 담당자가 처리하세요. 조합 씬에서는 구간의 XY 위치만 변경할 수 있고 구간 내부 수정은 원본 구간 작업 씬에서 해야 합니다. 변경을 마친 조합 씬과 프리팹, 각 `.meta` 파일을 함께 커밋하세요.

Inspector에서 직접 구간을 등록하는 기존 방법도 사용할 수 있습니다. 별도로 지정한 구간이 없으면 기존 테스트 맵이 그대로 사용됩니다. 연결한 구간들에는 전체적으로 `Marker_PlayerStart`와 `Marker_BallStart`를 하나씩 두고, 목표가 필요한 곳에 `Goal_Area`를 배치하세요. 같은 종류의 시작 마커가 여러 개면 배열 순서상 처음 발견된 마커를 사용합니다. 테스트 시작 마커는 실제 플레이 시작 위치에 영향을 주지 않습니다. 실제 플레이에서는 기본적으로 공을 카메라가 따라가며, `Follow Ball In Authored Maps`로 끌 수 있습니다.

Git에서는 서로 다른 고유 구간 폴더가 별도 파일이어서 각자 제작한 구간을 독립적으로 올릴 수 있습니다. 같은 구간 파일이나 공통 `PrototypeSystem.prefab`을 동시에 수정하는 경우에는 여전히 충돌할 수 있으므로, 구간 담당을 나누고 메인 맵 조합은 통합 담당자가 하세요. 모든 플레이어는 동일한 구간 설정이 포함된 같은 게임 빌드를 사용해야 합니다.
